# Trabajo 01 en grupo - Teoría de la Decisión

## Descripción

Este repositorio contiene el trabajo grupal de Teoría de la Decisión bajo Incertidumbre, realizado mediante RStudio, Quarto y GitHub.

El trabajo reúne seis problemas elaborados individualmente por los tres integrantes del grupo, junto con sus correspondientes resoluciones utilizando las funciones de R proporcionadas en la asignatura.

## Integrantes del grupo

- Miriam Moreno Tamayo

- Javier Ribelles Sánchez

- Eduardo LLovet Rojas

## Organización del trabajo

El trabajo se ha realizado de forma colaborativa mediante Git y GitHub.

Cada integrante ha aportado los dos problemas desarrollados en su trabajo individual, incorporando sus enunciados y resoluciones a los documentos comunes. Para facilitar la integración del código R, se han utilizado nombres de variables diferenciados para cada integrante.

Se ha trabajado sobre un mismo repositorio, registrando los cambios mediante commits y utilizando las issues de GitHub para organizar y revisar las tareas pendientes.

## Contenido del repositorio

- **Enunciados_trabajo_grupal.qmd:** documento Quarto con los enunciados de los seis problemas.

- **Resolución_trabajo_grupal.qmd:** documento Quarto con los problemas resueltos mediante R.

- **Archivos HTML y PDF:** versiones generadas a partir de los documentos Quarto.

- **teoriadecision_funciones_incertidumbre.R:** funciones utilizadas para aplicar los criterios de decisión bajo incertidumbre.

## Herramientas utilizadas

R, RStudio, Quarto, Typst, Git y GitHub.
